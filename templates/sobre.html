Sobre o Projeto

Este projeto foi desenvolvido por 3 alunos da disciplina Desenvolvimento Front-End Para Web com o objetivo de criar um site com tema livre. O principal objetivo é tornar o site interativo oferecendo uma biblioteca de jogos portados para serem jogados diretamente pelo navegador, proporcionando uma experiência divertida e acessível para os usuários. Além disso, o site inclui informações sobre os jogos informações relacionadas e uma seção de contato para o envio de mensagens e feedbacks.
